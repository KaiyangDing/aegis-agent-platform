== alembic 迁移链往返验证（M4.0④b，#4 剩余半边）  2026-08-03 ==

口径：本验证**不进 CI**（downgrade base 会清空业务表含演示种子，且拖长时长）——
一次性本地执行、结果落本凭证。CI 里常驻的是 `alembic check`（M4.0③ 已进，
位于 `alembic upgrade head` 之后）。

验的是什么：`alembic check` 只证"当前库与 ORM 元数据一致"，走的是**正向**。
8 个迁移里有 **4 个是手写 DDL**（RLS 角色与策略 / CREATE EXTENSION + HNSW 索引 /
mock 两表 + RLS / events AFTER INSERT 触发器），它们的 `downgrade()` 分支
**在此之前从未被执行过一次**。M4.7 容器化的回滚预案依赖这条能力。
