== 口径①：平台开销与并发容量（2026-08-04；模拟上游，全程零真实调用）==

环境（报告口径，D7/D12）：
- 部署形态：容器全栈 3×api 副本（uvicorn 单进程/副本）+ nginx（127.0.0.1:8080，
  proxy_buffering off + read_timeout 3600s）+ PG16/Redis7 单实例；镜像 aegis-app（M4.7）。
- 上游替身：LatencyModelProvider（首 token 800ms + 20 tok/s + 200 tok/响应——参数写死，
  测试钉死延迟计划）；embedding 检索向量同开关走进程内替身（零网络零计量）。
- 环境覆盖（docker-compose.loadtest.yml，全部进口径）：CACHE_TTL_SECONDS=0；
  PROVIDER_RATE/TENANT_RATE/INBOUND_RATE=200（默认 8/5/2 QPS 测的是限流墙不是容量）。
- 负载：locust 2.46 headless，-r 5 -t 180s；每虚拟用户一个会话串行发消息、prompt 唯一化；
  前 30s 预热段 stats.reset_all() 剔除（复盘补丁二稳态口径）；专用租户 lt-tenant
  （budget=0 闸关、零工具零语料——合成计量行隔离，不与任何真实账混流）。
- 请求路径：分诊（fast）→ 主 Agent（standard，无工具、检索空集装填）→ SSE 逐帧。

注入基线推导（平台开销的减数——本报告的口径核心）：
每请求两次上游调用全流 = 分诊(0.8s + 200×50ms) + 主调用(0.8s + 200×50ms) = 21,600ms。
合成同质 token 流（"测"×200，无句界）下输出守卫按整段 flush 释放——首个 token 帧
≈ 整响应到达，故 TTFT ≈ 注入基线 + 平台开销。两条已知失真如实声明：
①真实分诊回复是 1 词非 200 tok（失真只抬绝对时长，不影响减法后的开销）；
②真实文本含句界会更早流出（流式体验见真实 demo 与口径②，不由本口径背书）。

档位表（chat_first_token；平台开销 = TTFT − 21,600ms）：

结论：
- 三档 619 稳态请求 **零错误**；吞吐随并发线性扩展（1.28→3.79→7.71 req/s，
  受注入的 21.6s 请求时长天然限速——容量瓶颈未触及，60 并发下平台无退化迹象）；
- **平台自身开销：avg ≈ 0.4s，P99 ≤ 1.4s，最坏单样本 1.9s**（60 并发档；含准入/
  分诊编排/上下文构建/事件溯源落盘/投影/守卫/SSE 编码/nginx 转发全链）。
- 简历读数（M5.5 引用，限定语随数字走）：**本地压测（模拟上游延迟）60 并发 0 错误，
  平台自身开销 P99 ≤1.4s（TTFT P99 23s − 注入基线 21.6s）**。

样本量声明：P99 在 60/180/379 样本下按 locust 近似分位（千毫秒粒度）呈报，
avg/min/max 为精确值；两组口径分开呈现（口径② 见 m5_real_first_token.txt，绝不混排）。
