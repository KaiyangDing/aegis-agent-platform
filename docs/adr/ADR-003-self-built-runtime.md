# ADR-003 · 自研 Agent 运行时，不使用 LangChain / LangGraph

**状态**：Accepted　**日期**：2026-07

## 背景

Agent 循环的核心逻辑（循环控制、上下文组装、工具执行、状态持久化）可以自研，
也可以基于 LangChain/LangGraph/LlamaIndex 等框架搭建。

## 决策

**自研运行时**（约 2000–3000 行核心代码），不引入 Agent 框架。

（v1.2 实现期修订）供应商接入也改为 **httpx 直连**、不用 openai/anthropic SDK：
线格式仅是 POST+JSON，直连不增加代码量；更关键的是 SDK 内置自动重试/超时策略，
会与网关 M1.6 的自研受控重试**叠加成双重重试放大**（429 时火上浇油的经典事故），
自己控制 HTTP 层让重试策略全局唯一且显式。

## 理由

1. **项目定位**：这是能力证明型项目。框架把最有技术含量的部分（循环控制、状态管理、
   上下文工程）做成了黑盒，"我调用了 LangGraph 的 checkpoint 功能"与
   "我设计了事件溯源的状态机并处理了半截工具调用的幂等问题"在面试中是两个层次；
2. **可控性**：本项目的差异化功能——六道终止闸门、分层 token 预算、HITL 挂起与崩溃恢复
   共用代码路径——在框架里要么没有，要么要对抗框架的抽象去魔改；
3. **依赖成本**：LangChain 系版本迭代快、breaking change 多，学习框架 API 的时间
   不少于自研核心循环的时间。

## 备选方案

- **LangGraph**：其 graph + checkpoint 模型是好设计，checkpoint 也支持 time-travel 式
  回放调试（**表述纪律：不要说"它没有 replay"，2026-07-07 评审 C18 修正**）。真实差异在
  语义层级：checkpoint 是**图状态快照序列**（面向调试与断点恢复）；本项目的事件日志是
  **业务事实源**——审计留痕、同事务投影派生、HITL 挂起-恢复与崩溃恢复同路径、write-ahead
  幂等键都长在事件之上，这些是快照模型不提供、要自己在其上再造的；
- **Temporal / Restate 类 durable execution 引擎**（2026-07-07 评审 C19 补充对照）：
  workflow-as-code + 事件溯源重放是它们的成熟能力，若目标只是"可恢复执行"，选它们更稳。
  但本项目的技术核心恰是 LLM 特有的运行时问题——上下文预算编译、终止闸门、工具风险闸门、
  流式出口防护——这些 Temporal 一概不管；引入它等于把"最不需要证明的那一层"外包，
  还带来独立集群运维与单人项目不成比例的学习成本。面试反问"和 Temporal 什么关系"的答案：
  解决的问题域正交，我的差异化在 LLM 运行时语义，不在通用持久执行；
- **Dify / Coze / 百炼智能体等低代码 Agent 平台**：与 ADR-001 备选 2 同理——"用平台"
  不构成本项目要证明的能力；且多租户行级隔离、审批流状态机、事件级审计这类深度定制
  在低代码平台上受限；
- **仅用 LangChain 的组件（loader/splitter）**：文档解析等非核心环节允许用零散库
  （unstructured、tiktoken 等），不引入框架主干。

## 后果

- 收益：每一行核心代码可解释；面试深挖不设防区；
- 代价：自己承担稳定性与边界情况（所以 M2 的测试要求最重：七个终止条件全覆盖 +
  对抗用例 + 崩溃恢复测试）；放弃了框架生态的现成集成。

## 面试深挖点

- 辩证答法（重要）："不是框架不好，而是选型要匹配场景——团队要快速交付业务，用
  LangGraph 合理；要做平台层深度定制、吃透循环控制与状态恢复的原理，自研合理"。
  **表述纪律（2026-07-07 评审 C18）**：不声称读过其源码（除非开工前真读过并能说出
  具体设计点）——评估依据如实说"公开文档与 checkpoint 设计文章"；
- 准备好回答"LangGraph 的 checkpoint 和你的事件溯源有什么区别"：**快照序列 vs 事件日志**
  ——checkpoint 同样能 time-travel 回放，差异不在"有没有"，而在事件日志天然多出
  审计语义、同事务业务投影、"HITL 恢复与崩溃恢复同路径"这一层；代价是重放成本与
  事件 schema 演进问题（schema_version 解法见运行时详设 §5）。
